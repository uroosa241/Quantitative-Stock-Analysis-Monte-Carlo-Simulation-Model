#  Quantitative Stock Analysis & Monte Carlo Simulation

This project is a Python-based financial analysis system that evaluates and simulates stock behavior using real market data.

---

##  Project Overview

This project analyzes two major stocks:
- Apple (AAPL)
- Tesla (TSLA)

It combines financial ratio analysis, probability modeling, and Monte Carlo simulation to estimate possible future price ranges.

---

##  Features

### 1. Financial Ratio Analysis
- Profit Margin
- P/E Ratio
- Return on Equity (ROE)
- Debt-to-Equity Ratio
- Free Cash Flow Yield

### 2. Probability Analysis
- Probability of positive returns
- Probability of negative returns

### 3. Risk Analysis
- Mean return
- Standard deviation (volatility)

### 4. Monte Carlo Simulation
- 1000 simulated future price paths
- 30-day forecast
- Best case, worst case, and expected price

---

##  Model Used

- Log Return Model
- Empirical Probability Model
- Geometric Brownian Motion (GBM)
- Monte Carlo Simulation

---

##  Results (Apple Example)

- Expected Price: ~298.79
- Best Case: ~430.02
- Worst Case: ~214.24
- Volatility: ~1.97% daily

---

##  Important Note

This model does NOT predict exact stock prices.  
It provides a probabilistic range of possible outcomes based on historical data and volatility.
